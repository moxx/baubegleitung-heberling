# Heberling – Ökologische Baubegleitung & Bauaufsicht

Website von Mag. Oliver Heberling (One-Pager, statisch, ohne Build-Schritt).

- `index.html` – Startseite mit Video-Hero, interaktivem Nebel, Leistungen, Arbeitsweise, Über mich, Kontakt
- `media/` – Bilder (WebP) und Video-Loops (MP4), erstellt mit Higgsfield
- `visitenkarten/` – nicht verlinkte Freigabeseite für Visitenkarte und E-Mail-Signatur (noindex)
- `_headers` – Netlify-Header (noindex für die Freigabeseite)

Deploy: Ordner auf Netlify hochladen oder dieses Repo mit Netlify verbinden (kein Build-Befehl, Publish-Verzeichnis = Repo-Wurzel).

Offen: Kontaktformular ist noch an keinen Versand-Dienst angebunden; Impressum, Datenschutz und AGB sind Platzhalter.
